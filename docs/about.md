# 关于

## 这是什么

一份关于「如何驾驭当前大模型与编码智能体」的中文实践手册，由两部分组成：

- **[原始报告](/sources/)**：从模型厂商、一线大厂、Thoughtworks、资深独立工程师、X、中文技术社区、开源项目与学术研究中整理的 200 余条一手资料，每条附原文链接、中文摘要与证据性质标注。
- **[实践手册](/handbook/)**：在原始报告基础上提炼的 11 章方法论，每章都与传统软件工程认知做对比，并说明选择理由。

## 为什么写

用智能体写代码一段时间后，很多有经验的工程师都有同一个感受：它很能干，却守不住团队的工程与架构约束。这份手册试图回答：一线团队是如何解决这个问题的？哪些经典工程认知依然有效，哪些需要修正？

## 方法与局限

- 所有链接在 2026-11 实际打开核对；摘要忠于原文，引文逐字比对。
- 大部分资料是厂商与个人的经验报告，真正的对照研究很少，且结论相互冲突。手册用「共识 / 分歧 / 待验证」标注证据强度。
- 这一领域变化极快，一些结论可能在下一代模型上失效。请把它当作一份带日期的快照，而不是定论。
- 若发现错误、失效链接或遗漏的重要来源，欢迎提 issue。
