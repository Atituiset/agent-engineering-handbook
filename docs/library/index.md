## 这是什么、怎么用 {#about}

- **为什么要全量**：同一条实践被许多互不相干的人独立提出，本身就是证据。全量库用来统计这种「共识度」，结果见 [共识度/佐证](/compare/evidence)。
- **每行只有元数据**：标题或摘录（X 帖子取原帖开头的原文）、作者、日期、主题、原则标签、链接。**主题与原则是关键词自动归类**，可能有误。需要细读的，请看标了「精选」的条目或点原文。
- **链接都可追溯**：X 链接由 X API 返回的帖子 ID 生成；HN 链接来自 HN Algolia / Firebase API；GitHub 链接来自 GitHub 搜索 API；精选与中文网页逐条打开核对过。检索时间为 2026-11 中旬。
- **数据下载**：[sources.json](/data/sources.json) · [sources.csv](/data/sources.csv)（每行：编号、来源、分类、标题、作者、日期、链接、主题、原则、精选锚点、热度、专题；质量专题的行在「原则」中还带有 Q01–Q13 标签，「专题」为 `quality-cicd`；国内大厂专题的行「专题」为 `cn-bigtech`，另有「公司」列/`co` 字段）。
- **不代表背书**：收录不等于推荐。X 帖子与 GitHub 描述是作者的一面之词，厂商人员谈自家产品属于厂商自报。
