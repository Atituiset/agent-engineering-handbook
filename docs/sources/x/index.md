## 读法与局限 {#notes}

- **作者自述**：X 上多是个人经验，样本小、语境短。厂商员工（Anthropic、OpenAI、Cursor、GitHub 等）谈自家产品时，属于**厂商自报**。
- **长帖已核对全文**：搜索接口有时会截断长帖，这类帖子都用按 ID 读取的接口取回全文后再写摘要和引文。
- **日期**：按发帖时间的 UTC 日期。
- **分歧也收**：例如「plan mode 不必要」「skills 大多是噪声」「严格 harness 正在过时」等，都作为异议收录，并在 [共识度/佐证](/compare/evidence) 里列出。
